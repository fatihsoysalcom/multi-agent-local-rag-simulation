# Multi Agent Local RAG Simulation

This example simulates a multi-agent system demonstrating Retrieval Augmented Generation (RAG). A Retrieval Agent fetches information from a local knowledge base, which is then used by a Generation Agent to formulate a context-aware response. It highlights how AI agents can collaborate and leverage local data for enhanced privacy and relevance, mirroring concepts discussed in the ICECODE article.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
